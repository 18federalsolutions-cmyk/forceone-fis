# ForceOne-FIS Website

Editable static website for the ForceOne-FIS joint venture. No build tools or software installation are required.

## Main files

- index.html - homepage content and navigation
- styles.css - colors, typography, layout, and mobile styling
- assets/forceone-fis-capability-statement.pdf - downloadable capability statement
- assets/capability-statement-preview.html - editable capability-statement source preview
